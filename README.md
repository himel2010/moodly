# Moodly

Mood based media hub

## Tech Stack
Next.js • PostgreSQL • Supabase • Ingest

## Features
- Mood based movie recommendations
- Mood based song recommendations
- Dyanmic theme changing based on mood
- Gamification with point system and shops
- Live Stream / Radio with Chat to view with others
- Personalized live rooms to watch with friends
